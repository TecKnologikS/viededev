Pourquoi j'ai lâché RevenueCat pour StoreKit 2

84aee3218 nov. 20261 min de lecture#ios #achats

Trente30 utilise désormais StoreKit 2 seul, sans service tiers. J’ai abandonné RevenueCat.

L’app ne propose qu’un seul achat non consommable, pack_2026, à 2,99 €. Dans les Réglages, un bouton « Restaurer mes achats » permet de retrouver son achat.

Une règle commune

Le 05/11/2026, j’ai décidé d’une règle commune pour les apps du monorepo :

  • StoreKit 2 sur iOS ;
  • Google Play Billing sur Android ;
  • pas de service tiers ;
  • l’identifiant produit du store sert d’identifiant de droit.

Un exemple

Voici l’idée, de façon illustrative, pour lire les droits de l’utilisateur :

for await result in Transaction.currentEntitlements {
    if case .verified(let transaction) = result,
       transaction.productID == "pack_2026" {
        // Droit actif
    }
}

Ce que j’assume

Sans compte, un achat n’est pas partagé entre iOS et Android. C’est une conséquence assumée de ce choix.
